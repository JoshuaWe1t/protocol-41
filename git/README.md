# Как зафиксировать версию кода (Git Tags)

```bash
# Создаем тег с именем версии и описанием
git tag -a v1.0.0-demo -m "Готовый web-билд демо-версии"
```

```bash
# Отправляем тег в удаленный репозиторий (например, на GitHub)
git push origin v1.0.0-demo
```

# Где хранить сами файлы билда?

## GitHub Releases (Для хранения архивов)

1. Зайди на страницу своего репозитория на GitHub.
2. Справа найди раздел Releases и нажми Draft a new release.
3. Выбери тег, который ты только что создал (`v1.0.0-demo`).
4. Запакуй папку с web-билдом в ZIP-архив и перетащи в поле прикрепленных файлов (Assets).
5. Опубликуй релиз.

## Ветка gh-pages (Для игры прямо в браузере)

```bash
# Создаем пустую изолированную ветку
git checkout --orphan gh-pages
```

```bash
# Удаляем все исходники из индекса этой ветки
git rm -rf .
```
```bash
git add .
```

```bash
git commit -m "Публикация web-билда v1.0.0-demo"
```

```bash
git push origin gh-pages
```

## Удалить тег локально (на твоем компьютере)

```bash
git tag -d <имя_тега>
```

## Удалить тег удаленно (на GitHub)

```bash
git push origin --delete <имя_тега>
```
